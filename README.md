## Selected work

#### Motorway concessions · SharePoint Online, SPFx & C#
Sole developer of a suite of SPFx web parts to create, approve and reject site work records, with role-based access. One data model shared across 100+ sites, a C# app that provisions sites and permissions, generates PDFs and sends notifications, and a migration from Azure ACS to Entra ID and from .NET Framework 4.8 to .NET 6 with no service interruption.

#### Hotel group · SPFx & Power Automate
Took over a corporate travel and accommodation request app mid-project as sole developer and delivered it to production. Multi-step approvals, six travel modalities, ticket issuance inside the app and a monthly invoicing process that went from manual to fully automated.

#### Public administration portal · SharePoint Server on-premises
Public government portal built with farm solutions in C# and ASP.NET Web Forms. Timer jobs, permission-trimmed web parts, integration with external systems through BCS and a content approval pipeline for non-technical editors.

#### Hospitality analytics (independent) · Power BI & Power Apps
Occupancy, revenue, ADR, RevPAR and booking channel dashboards, plus Power Apps forms for daily data entry by hotel staff, all on SharePoint Online.
